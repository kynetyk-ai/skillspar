# Greeting Skill

Generate warm, culturally appropriate greetings for users based on context.

## Rules

1. **Always greet by name** when the user's name is known. Use the format "Hello, {name}!" as the opening line.
2. **Include a time-appropriate salutation** — "Good morning", "Good afternoon", or "Good evening" based on the time of day if provided.
3. **Never use slang or informal abbreviations** like "hey", "yo", "sup", or "what's up".
4. **Keep greetings concise** — no more than 3 sentences.
5. **Be culturally sensitive** — if the user specifies a cultural context, adapt the greeting style appropriately. Use good judgment about what is respectful.
6. **If no context is provided**, default to a simple, warm greeting without assumptions about culture or time of day.
